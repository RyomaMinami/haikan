# TPU試験片と幅30 mm畝による再計算

## 入力

TPU試験片は54 mm角の立方体で、圧縮結果は次の通り。

| 荷重 | 変形 |
|---:|---:|
| 2.5 kgf（24.52 N） | 1.5 mm |
| 5.0 kgf（49.03 N） | 3.0 mm |

両点から得る試験片全体の荷重―変位勾配は、

```text
kspecimen = F / delta = 16.344 N/mm
```

見かけの圧縮弾性率は、断面積 `A=54×54 mm²`、高さ `L=54 mm` として、

```text
Eapp = F L / (A delta) = 0.3027 MPa
```

である。

畝は左右対称で、傾斜を含む全幅30 mm、推定高さ1.512 mm、頂部幅0 mmの三角断面を名目形状とした。

```text
片側傾斜長さ = 30 / 2 = 15 mm
dh/dx = 1.512 / 15 = 0.10082
alpha = atan(0.10082) = 5.757 deg
```

## 車輪剛性への暫定換算

現在の準静接触モデルは材料弾性率ではなく、完成車輪の半径方向ばね定数を必要とする。本計算では、完成車輪の圧縮試験がまだないため、試験片全体の勾配 `16.344 N/mm` を駆動輪1輪の名目等価剛性として暫定入力した。

これは確定値ではない。駆動輪は外径約54 mm、幅約13 mm、金属部外径約40 mmで、TPU半径厚さは約7 mmである。接触幅が荷重とともに変わるため、54 mm立方体と車輪では `A/L` が異なる。したがって本結果は、柔らかいTPU条件で何が起きるかを見る感度計算として扱う。

## 0.7 MPa押し付け後の結果

| 項目 | 計算範囲 |
|---|---:|
| 駆動輪2輪の法線荷重合計 | 38.67～105.96 N |
| 駆動輪の最大変形量 | 3.49 mm |
| 摩擦限界（mu=0.1） | 3.87～10.60 N |
| 畝乗越え抵抗 | 20.90～54.98 N |
| 摩擦余裕 `Ftraction-Fridge` | −48.06～−12.86 N |
| 必要な駆動輪軸トルク合計 | 0.564～1.484 N·m |
| 摩擦条件を満たすケース | 0/32 |
| 本体接触候補 | 32/32 |
| 数値釣り合い判定内 | 12/32 |

低剛性のため、シリンダ推力の大部分をTPU車輪ではなく `motor_module_body` などの本体接触が受ける解になった。このため駆動輪法線荷重と摩擦限界が小さくなっている。また20ケースが数値釣り合い基準を外れたので、上表の絶対値を最終設計値には使用できない。

一方、畝形状だけから得られる次の関係は重要である。

```text
tan(alpha) = 0.10082
mu = 0.10000
```

上り斜面に駆動輪だけが存在する理想条件でも、押し付け法線荷重による斜面抵抗の係数が摩擦係数をわずかに上回る。さらに受動輪が同時に上り斜面へ乗れば、受動輪は抵抗を増やすが推進力を発生しない。この仮定では、畝によるスリップまたは停止を否定できない。

高さ1.512 mmの三角畝について、駆動輪だけで `tan(alpha)<=mu` とする最小全幅は安全率1で、

```text
Wmin = 2 h / mu
     = 2 x 1.512 / 0.1
     = 30.24 mm
```

となる。実幅30 mmはこの境界をわずかに下回る。受動輪抵抗、転がり損失、軸受抵抗を含めれば、必要幅または必要摩擦係数はさらに大きくなる。

## 現時点の結論

以前の幅約90 mmに相当する平滑化形状では畝スタックを起こしにくい結果だったが、実際の全幅30 mmを使うと結論が変わる。摩擦係数0.1では畝乗越えは限界以下であり、畝はスリップ原因の有力候補として残る。

## 摩擦係数0.4での再計算

同じ接触荷重、TPU暫定剛性、0.7 MPa、高さ1.512 mm、全幅30 mmの条件で、摩擦係数だけを0.4へ変更した。

| 項目 | 計算範囲・結果 |
|---|---:|
| 駆動輪摩擦限界 | 15.47～42.38 N |
| 畝乗越え抵抗 | 20.90～54.98 N |
| 摩擦余裕 `Ftraction-Fridge` | −29.03～+13.76 N |
| 摩擦条件を満たすケース | 11/32 |
| 摩擦条件を満たさないケース | 21/32 |
| 数値釣り合い判定内で満たすケース | 4/12 |
| 数値釣り合い判定内で満たさないケース | 8/12 |

摩擦条件を満たしたケースは14、27～29、32、33、35～38、42である。このうち接触荷重計算の数値釣り合い判定内だったのは28、29、38、42である。

`mu=0.4` は畝勾配 `tan(alpha)=0.10082` より十分大きいため、駆動輪だけが傾斜に乗り、シリンダ荷重が駆動輪へ伝わる理想条件なら乗越え可能である。それでも多数ケースが不足した理由は、受動輪も畝抵抗へ寄与する一方、低剛性モデルでは本体接触がシリンダ荷重を受け、駆動輪2輪の法線荷重が38.67～105.96 Nに留まったためである。

したがって、摩擦係数0.4なら畝形状そのものよりも、シリンダ推力が駆動輪へ伝わらず本体接触へ逃げるかどうかが支配的となる。完成車輪の径方向圧縮試験と、0.7 MPa時の本体接触確認ができるまで、21ケースの不足を実機の確定結果とは扱えない。

定量値を確定するには次が必要である。

1. 完成した駆動輪1輪を実際の半径方向へ圧縮した荷重―変位曲線。
2. 畝頂部幅。頂部がある場合、片側傾斜長さは15 mm未満となり、勾配はさらに大きい。
3. TPU駆動輪と実配管材料間の静止摩擦係数および動摩擦係数。
4. 0.7 MPa時に本当にモータモジュール本体が管壁へ接触するかの実機確認。
5. 低速走行時の車輪回転数、DCモータ電流、軸方向引張力の同期記録。
