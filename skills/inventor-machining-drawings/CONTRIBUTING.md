# 試用・改善の共有手順
## 最初に試すこと
1. Windows・Python・Inventorの版とClaude Codeの利用形態を記録する。
2. doctorの結果を確認し、自分で公開可能な単純モデルで下書き生成を試す。
3. 製図ルールを適用して寸法計画→作図→全頁検図を行う。最初から実加工へ使わず、仕様未確定は確認用と明示する。
4. 対称軸、全穴列の起点/送り、十字/接続中心線、注記の輪郭外配置を別々に確認する。

## 気づいたことを共有する
リポジトリのIssuesで「図面作成スキルの試用報告」テンプレートを使う。利用版、環境、入力の特徴、再現手順、期待結果、実結果、加工者が迷った箇所、修正案を記す。PDF全頁目視か文字照合だけかを区別する。
公開Issueには公開可能な合成例・切り出し画像だけを添付する。顧客図面や機密モデル、個人パスを含むログをそのまま貼らない。再現モデルを公開できない場合は、穴数・寸法・配置を一般化して説明する。

## 改善を取り込む
ルールはrules、AI固有の手順はruntime、利用者固有値はprofiles、処理はscriptsへ分ける。個別モデルの曲線番号や絶対パスを共通処理へ固定しない。相手AIや他案件へ適用できる条件を明記する。
変更案はブランチで作成してPull Requestへ。指摘→変更→検証結果を記し、別担当の検図後に取り込む。原本CADをGitHubへ追加することは、このスキルの共有依頼に含まれない。
変更時はCHANGELOGを追記し、必要なら版を上げる。manifest.jsonは配布対象ファイル（manifest自身・Pythonキャッシュを除く）のSHA256へ更新する。実行していないCAD/Claude試験を合格にしない。

## 更新を受け取る
1. cloneしたhaikanで `git pull --ff-only`。自分の修正がある場合は先に別ブランチ等へ保存する。
2. 現在の導入先スキルを別名で退避し、独自設定の差分を確認する。
3. 退避後、既存導入先がない状態で `python scripts/install.py --target claude` を再実行する。install.pyは上書きしない。
4. 必要なprofiles変更を移し、doctorと試験モデルで再確認する。更新元はこのGitHubのフォルダ、導入先は実行用コピーとして扱う。
