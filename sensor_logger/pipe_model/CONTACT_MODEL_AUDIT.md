# 配管内接地シミュレーションの計算式と精査結果

## 結論

現在の処理は、**押し付け前の受動輪接地組合せ**と、シリンダを伸ばしたときの**駆動輪1・2の最初の幾何接触**を比較する用途には使えます。ただし、0.7 MPaで押し付けた後の最終接地・荷重分配・スリップまではまだ計算していません。

2026-09-21の精査で次を修正しました。

- 穿孔モジュール角度を30°刻みから5°刻みにし、−90～+90°を再走査。
- 穿孔部だけでなく、移動体フレームと押し付けモジュール本体も配管干渉判定へ追加。
- 車輪メッシュは本体メッシュから除外し、車輪ばねと本体接触を二重計上しないようにした。
- 鉛直力だけでなく横方向残差と、移動体ロール0°を保持するための拘束トルクを算出。
- 駆動・押し付け対象は穿孔モジュールと反対側の輪1・2のみ。輪3・4は実機のがたで下がるため支持対象外。

精密検証を通過した代表点は32組です。内訳は穿孔部0°が8組、事前回転状態が24組です。事前回転代表点の角度は−5～+30°ですが、角度ごとの最大隙間候補を別に検証すると、5°サンプル上で成立した連続範囲は−20～+30°でした。±90°では本体干渉が発生しました。32組は確認済みの接地トポロジーであり、連続空間に存在する全ケース数の証明ではありません。

## 座標系と形状変換

- シミュレータX：配管軸方向
- シミュレータY/Z：配管断面
- `alpha`：移動体に対する穿孔モジュールの回転9
- `phi`：移動体全体のロール。今回の投入解析では `phi = 0°` に拘束

穿孔部の点 `p` は、回転9軸上の点 `c9` を用いて次のように変換します。

```text
p_rot = c9 + Rx(alpha) (p - c9)
p_world = t + Rx(phi) p_rot
```

`t = (x, y, z)` は移動体の並進です。今回 `phi=0` なので、回転するのは穿孔モジュール側だけです。

## 推定配管内面

螺旋1回転のリードを `L = 189.5 mm`、角度を `theta = atan2(z,y)`、真上の畝基準位置を `x0` とします。右巻き螺旋の畝中心からの位相距離は次式です。

```text
q = wrap(x - x0 - L theta / (2 pi), -L/2, L/2)
d = |q|
```

実測した90%、80%、50%高さ幅を節点として畝高さ `h(d)` を線形補間し、内面半径を

```text
Rpipe(x,theta) = 120 mm - h(d)
```

とします。これは実測範囲から全周へ一般化した推定面であり、実管全長を直接測った形状ではありません。

## 車輪・本体の隙間

車輪または本体メッシュの各頂点 `pj=(xj,yj,zj)` について

```text
rj = sqrt(yj^2 + zj^2)
gj = Rpipe(xj, thetaj) - rj
g = min(gj)
```

を計算します。

- `g > 0`：配管面との隙間あり
- `g = 0`：幾何接触
- `g < 0`：仮想的な押し込み、または本体干渉

本体成立判定では全対象本体の最小隙間を使い、高精度検証の許容侵入量は0.005 mmです。

## 重力着座と仮想ばね

車輪の押し込み量は

```text
delta_i = max(0, -g_i)
```

で、現在は全受動輪に線形ばねを仮定しています。

```text
N_i = kw delta_i
kw = 200 N/mm（暫定値）
```

本体干渉には

```text
Nb = kb delta_b
kb = 5000 N/mm（数値計算用の暫定値）
```

を使用します。質量 `m=21 kg`、重力加速度 `g0=9.80665 m/s^2` とし、次のポテンシャルを最小化してY/Z位置を求めます。

```text
Pi(y,z) = m g0 zG
          + 1/2 sum(kw delta_i^2)
          + 1/2 sum(kb delta_b^2)
```

高さと押し込みはmm、力はNなので、`Pi` の単位はN mmです。今回は移動体ロールを `phi=0°` に拘束しているため、最小化変数はY/Zだけです。

## 重心

モジュール別質量が未入力なので、現在はSTL囲み体積を質量比の代用にしています。

```text
rG = sum(Vj rGj) / sum(Vj)
```

穿孔部の重心だけは回転9に追従させます。一部STLが非水密で、材質・内部部品・基板・配線を反映していないため暫定重心です。

## 力とロール保持トルク

接触点で配管中心へ向く単位法線を

```text
ni = -(0, yi, zi) / sqrt(yi^2 + zi^2)
Fi = Ni ni
```

として、次を検査します。

```text
vertical residual = sum(Fi,z) - m g0
lateral residual  = sum(Fi,y)
```

成立代表点は、両残差の絶対値が5 N以下です。実際の精密代表点では鉛直残差最大約0.35 N、横残差最大約0.87 Nでした。

移動体ロール0°を保つ外力トルクは、重心まわりで

```text
T_hold,x = - sum(((pi - rG) cross Fi)_x)
```

です。成立代表点では約−1.14～+0.026 N mでした。角度別の最大隙間候補では−20°時に約−1.51 N m必要です。シリンダ押し付けがこの保持トルクを発生できるかは未検証です。

## 接地輪と畝上の分類

各受動輪の反力から

```text
support set S = {i | Ni >= 2 N}
```

を接地輪とします。接触点の局所畝高さ

```text
hridge = 120 mm - Rpipe(contact point)
```

が0.7 mm以上なら

```text
ridge set R = {i in S | hridge >= 0.7 mm}
```

を畝上接触輪とします。場合分けのキーは

```text
(穿孔部が0°か事前回転か, S, R)
```

です。ユーザー方針に従い、同じ `S` と `R` で角度・軸方向位相だけが違う状態は同じ接地トポロジーとしてまとめ、最も本体隙間が大きい点を表示代表にしています。したがって表示ケースは荷重値まで同一という意味ではありません。

## 場合分けの探索手順

1. 螺旋1リード189.5 mmを38分割し、実間隔約4.99 mmで走査。
2. 穿孔部初期角度を−90～+90°、5°刻みの37角度で走査。
3. 合計 `38 x 37 = 1406` 状態を粗い表面サンプルで計算。
4. 移動体受動輪だけで着座した解を初期値にする。
5. 穿孔側受動輪を追加し、全受動輪で再着座。
6. 接地集合 `S` と畝集合 `R` で分類。
7. 各分類で本体隙間が最大の代表点を、フルメッシュで再計算。
8. 本体侵入0.005 mm以下、鉛直・横力残差5 N以下を成立条件とする。
9. 最後に駆動輪1・2を幾何接触まで押し上げる。

粗探索後に同じ `(0°か事前回転か, S, R)` をまとめ、最小本体隙間が最も大きい1点だけを精密検証しています。精密検証後には `(0°か事前回転か, S, R, 駆動輪接触集合)` が一致するものを重複としています。現在の32組にはこのキーの重複はありません。

## 駆動輪の最初の接触

シリンダ変位を `s` とすると、駆動輪 `i` の接触変位は

```text
gi(s_i) = 0
```

の根です。実機構成に合わせ、候補は穿孔部と反対側の駆動輪1・2だけです。

```text
s_stop = min(s_1, s_2)
```

輪3・4は機械的ながたで下がるため支持対象外ですが、下がり量が未測定なので画面ではCAD位置のまま灰色表示しています。

## 精査で残った重要な問題

### 1. 押し付け後の状態ではない

現在は `s_stop`、つまり最初の駆動輪が触れた瞬間で止めています。シリンダ圧力による力を入れていないため、押し付け後に駆動輪2が接触するか、受動輪のどれが浮くか、荷重がどう分配されるかは未計算です。

今後必要な式は

```text
Fcyl = P Aeff eta
Fdrive,i = fTPU(delta_i)
sum(F) = 0
sum(M) = 0
sum(Fdrive,i projected to cylinder axis) = Fcyl
```

シリンダ径を `D`、ロッド径を `d` とすると、理論推力は

```text
押出側: Fcyl,out = P pi D^2 / 4
引込側: Fcyl,in  = P pi (D^2 - d^2) / 4
実推力: Feff = eta Fcyl
```

です。例えば内径32 mm、0.7 MPaの押出側理論値は約563 Nですが、実解析には使用方向、ロッド径、摩擦を含む効率 `eta`、リンクや案内の損失を入れる必要があります。

です。`fTPU` はTPU95A実車輪の荷重－変位試験から求めます。ヒステリシスが大きければ押し込み時と戻し時を別曲線にします。

### 2. 移動体ロール0°は外部拘束

ロール角を計算で固定しているため、上記 `T_hold` をどの機構が受けるかを確認する必要があります。押し付け輪、受動輪、フレームの接触だけで保持できるかは、押し付け後解析で確認します。

### 3. 重心とばね定数が暫定

- 重心：STL体積比。実測重心またはモジュール別質量へ置換が必要。
- 受動輪剛性200 N/mm：仮定。車輪・支持部を含めた荷重－変位測定が必要。
- 本体剛性5000 N/mm：物性値ではなく侵入を抑える数値ペナルティ。

### 4. 摩擦・スリップを扱っていない

現在は法線方向だけです。走行可能性には

```text
|Ft,i| <= mu_i Ni
sum(Ft,i) >= required traction
```

と、車輪トルクによる要求接線力 `Ft = T / rwheel` が必要です。動摩擦・静止摩擦、畝への引っ掛かり、TPUの接触面積は未反映です。

### 5. 離散探索と推定配管

5°・約5 mm刻みなので、その間に狭い成立域が残る可能性があります。角度別フルメッシュ監査では成立サンプルが−20～+30°で連続し、その外側は本体干渉しましたが、これは現在の推定配管と暫定重心に対する結果です。

### 6. 代表点方式は完全列挙ではない

粗探索で同じ接地トポロジーになった状態のうち、本体隙間が最大の1点だけをフルメッシュで再計算しています。その代表点が不成立でも、同じ粗分類内の別位相が成立する可能性は残ります。したがって32組は現時点で確認できた下限側の数です。完全列挙には、粗探索で成立した全状態をフルメッシュ再計算し、再計算後の `S`、`R`、駆動輪接触集合で再分類する必要があります。

### 7. 「先に下側を接地」は厳密な経路拘束ではない

移動体側受動輪だけで求めた解を、穿孔側受動輪を加えた次の最適化の初期値にしています。このため投入順序の影響は初期値として入りますが、前段の接触輪を離さない拘束や、摩擦による履歴依存までは入っていません。厳密に再現するには、シリンダ変位を微小増分で進める非線形接触解析と、各増分での非貫通条件・摩擦条件が必要です。

### 8. 頂点基準・集中接触の近似

隙間はSTL頂点から解析配管面までの最小値で求め、各車輪・各本体について最小点1点に反力が集中すると仮定しています。面の途中で生じる接触や複数点接触、接触面積、TPUの局所変形は表現していません。メッシュ分解能依存性を確認するか、符号付き距離場と分布接触へ置き換える必要があります。
