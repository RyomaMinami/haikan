# 0.7 MPa押し付け時の畝乗越え評価

## 結論

実測レーザデータから推定した螺旋畝と、0.7 MPaで押し付けた後の32接地ケースを用いて、配管軸方向へ走行したときの畝乗越え抵抗を計算した。

- 車輪に作用する畝抵抗（位相を考慮）：14.81～31.91 N
- 摩擦係数0.1とした駆動輪2輪の摩擦限界：43.23～59.90 N
- 畝抵抗を差し引いた摩擦力の余裕：27.83～38.58 N
- 畝乗越えに必要な駆動輪軸トルク：合計0.400～0.862 N·m
- 2輪で均等負担する場合：1輪当たり0.200～0.431 N·m
- 車輪の摩擦限界を畝抵抗が超えたケース：0/32
- 車輪以外の本体接触候補があるケース：13/32

したがって、現在推定している滑らかな畝を**車輪が転がり越えることだけ**で幾何学的にスタックする可能性は低い。一方、穿孔モジュールやモータモジュールが畝・管壁へ接触して引っ掛かる可能性、未計測の鋭い畝端、駆動モータのトルク不足は、この計算だけでは否定できない。

ばねばかり実験で必要だった補助力4 kgf（39.23 N）に対し、位相を考慮した滑らかな畝抵抗の最大値は31.91 Nだった。畝抵抗は無視できないが、それだけでは4 kgfをすべて説明しない。全接触点が同時に最大勾配に乗る保守値は34.63～48.76 Nであり、畝形状の局所的な鋭さには注意が必要である。

## 使用条件

| 項目 | 値 |
|---|---:|
| シリンダ圧力 | 0.7 MPa |
| シリンダ内径 | 32 mm |
| 理論推力（効率1.0） | 562.97 N |
| 摩擦係数 | 0.1 |
| 駆動輪有効半径 | 27 mm |
| 推定畝高さ | 1.512 mm |
| 推定螺旋リード | 189.5 mm/rev |
| 位相平均した最大表面勾配 | 0.03375 |
| 最大表面角 | 1.933° |

畝形状は `pipe154_auto_scan_m115_115_point_cloud_axis_corrected.csv` から得た。螺旋推定の決定係数は `R²=0.424` であるため、形状値は確定値ではない。

## 計算式

シリンダ理論推力は、圧力 `P`、内径 `D` に対して次式とした。

```text
Fcyl = P pi D^2 / 4
     = 0.7 x pi x 32^2 / 4
     = 562.97 N
```

螺旋畝上の接触点の位相 `q` は、配管軸位置 `x`、周方向角度 `theta`、リード `L`、基準位相 `x0` から求めた。

```text
q = x - x0 - L theta / 360
```

0.7 MPa押し付け後の各車輪の法線荷重 `Ni` を固定し、実測から位相平均した畝高さ `h(q)` の勾配を使って軸方向抵抗を計算した。

```text
Fridge(x) = sum[Ni dh(qi + x)/dx]
```

駆動輪の静止摩擦限界と、畝乗越えに使用可能な推進力は次の通りである。

```text
Ftraction = mu sum(Ndrive)
Favailable = min(Tout / rwheel, Ftraction)
```

実際に乗り越える条件は、転がり抵抗、軸受抵抗、ケーブル抵抗などを `Fother` として、

```text
Favailable > Fridge + Fother
```

である。本計算では `Tout` が未確認のため、摩擦力側の条件のみ確認した。

参考として、高さ1.512 mmの完全な垂直段差を半径27 mmの剛体輪が越える静的モデルでは、必要水平力と法線荷重の比は約0.350となる。これは実測の滑らかな位相平均形状より厳しい比較値であり、実際の畝端が未解像の鋭い段差なら必要力が増えることを示す。

## エアシリンダ推力の意味

押し付け力を増やすと、駆動輪の摩擦限界 `mu Ndrive` は増える。しかし同時に、各車輪が畝斜面から受ける抵抗 `Ni dh/dx`、TPUの変形損失、本体接触時の引っ掛かりも増える。したがって「圧力を上げれば必ず畝を越えやすくなる」とは限らない。

このモデルでは0.7 MPaで駆動輪の摩擦力は足りている。よって次に確認すべきなのは、モータ出力トルクと車輪以外の接触である。

## 畝スタック説を判別する実験

1. 0.3、0.5、0.7 MPaで同じ低速走行を行い、走行距離、車輪回転数、DCモータ電流を同時記録する。
2. 停止時に車輪回転数が維持されるならスリップ、回転数低下と電流上昇が同時に起こるなら機械的スタックまたはトルク不足と判定する。
3. 配管軸方向の引張力をロードセルまたはばねばかりで測り、平滑部と畝乗越え時の差を取る。
4. 穿孔モジュールとモータモジュールの管壁側へ感圧紙またはチョークを付け、本体接触痕を確認する。
5. 力・電流ピークが螺旋リード約189.5 mmごとに再現するかを確認する。周期が一致すれば畝の寄与が強い。
6. TPU試験片の荷重―変位曲線と転がり損失を取得後、線形ばね仮定を実測曲線へ置き換えて再計算する。

判定の目安は次の通りである。

| 観測 | 有力な原因 |
|---|---|
| 車輪は高速回転、ロボットは停止 | 駆動輪スリップ |
| 車輪回転低下＋電流上昇 | 畝・本体のスタック、またはモータトルク不足 |
| 押し付け圧を上げると改善 | 摩擦力不足の可能性が高い |
| 押し付け圧を上げると悪化 | 本体接触、畝抵抗、TPU変形損失の可能性が高い |
